# 崑山科技大學 招生網站 (KSU Recruit)

現代化、響應式、對行動裝置友好的崑山科技大學 115 學年度招生形象網站。

## 特色

- **設計語言**：專業 + 年輕世代審美 — 海軍藍 × 強調橘，大字體、大留白、漸層裝飾
- **完全響應式**：桌機、平板、手機自動調整；行動裝置選單、觸控優化
- **無障礙設計**：語意化 HTML、aria 屬性、跳至主要內容、鍵盤導覽、`prefers-reduced-motion` 支援
- **效能**：純靜態 HTML + CSS + JavaScript，無需建置工具，瀏覽器直接開啟
- **互動**：
  - 滾動時 Header 樣式變化
  - Hero 浮動卡片、底部跑馬燈
  - 招生管道頁籤切換
  - 表單驗證與送出
  - 數字計數動畫、區塊淡入

## 啟動方式

由於環境中無 Node.js，本專案為純靜態網站：

### 方法 1：直接開啟
雙擊 `index.html` 即可在瀏覽器中查看。

### 方法 2：本機伺服器（推薦，避免某些資源限制）
```bash
# Python 3
python -m http.server 5173

# 或使用 PowerShell 內建 server
```

開啟 `http://localhost:5173` 查看。

## 設計系統

### 色彩
- **主色**：`#0A2540` 海軍藍（專業、信任）
- **強調色**：`#FF6B1A` 橘（年輕、能量）
- **中性色階**：`#F4F6FA` → `#0A1626` 共 9 階

### 字型
- **英文**：Inter、Space Grotesk
- **中文**：Noto Sans TC

### 區塊
1. **Header**：固定式，背景模糊，捲動變化
2. **Hero**：標題、雙 CTA、4 項數據、3 張浮動視覺卡、底部跑馬燈
3. **5 大學院**：卡片式 grid，包含科系 chips
4. **辦學特色**：6 個數字亮點（私校產學第一、教卓 12 年、深耕 5.5M、650 師資、IEET/ACCSB、60 年）
5. **產學合作**：深色區塊，3 個專班說明 + 4 張數據卡
6. **校園生活**：不對稱 grid，4 個場景卡
7. **招生管道**：頁籤切換 + 時程時間軸
8. **校友故事**：3 個引用卡（含特色卡）
9. **CTA 表單**：姓名/Email/電話/興趣學院
10. **Footer**：4 欄，含聯絡資訊
